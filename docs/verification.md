# QuickADB 0.1.0 验证记录

## 本地协议与状态验证

- 应用安装/队列集成测试：10 项通过。
- SDK 配对测试：12 项通过，包含 SPAKE2 协议向量、错误配对码、配对凭据持久化和重新连接的协议夹具。
- 覆盖官方 ABB 参数分隔、实际 APK 字节传输、确认后进度、取消、设备拒绝、最终结果丢失、拆分包会话及清理、旧设备能力分支。
- 两台夹具设备并行传输，同一设备按提交顺序安装。取消设备选择不改变已提交任务的目标。
- 授权私钥以 DPAPI 保护；重新打开数据目录保留同一身份。损坏的设置文件明确失败，不静默重置。
- 安装测试的 APK 是二进制 Manifest/ZIP 夹具，服务端是本地协议夹具，不是 Android 手机或签名发布包。

## 构建与窗口

- 静态 C 运行库构建、Cargo.lock 锁定依赖。
- 原生应用 Clippy 严格检查通过。
- Release 导入表只包含 Windows 系统 DLL，没有外部 ADB、.NET 或应用 DLL。
- Release 已检查静默托盘启动、托盘展开、关闭后继续常驻、再次展开和退出菜单结束进程。
- 设备列表已使用实际应用连接本地协议夹具，检查多选、连接状态、长备注截断。
- 字号、主题、连接弹窗和拖放区按 docs/ui-layout.md 进行最终窗口验收；截图与测量输出保存在忽略的 logs 目录。
- 实际控件测量：两个 APK 操作按钮均为 178 × 40，按钮组居中偏差 0.5，按钮间距 9，提示文字与按钮间距 16 个逻辑像素。
- 样式绑定到应用选定主题，避免启动后的系统主题输入切换到默认字号。辅助文字为 13，实测提示文字高度为 17 个逻辑像素。
- 浅色与深色连接弹窗在淡入动画结束后检查，标签、输入提示、准备说明和操作按钮无重叠；主文字、辅助文字及选中状态分别使用对应主题颜色。

## 真机验收缺口

用户目前无法提供真机，本机 ADB 设备列表也没有连接的手机。以下内容没有用真机验证：USB 驱动与手机授权、Android 无线配对、签名 APK 实际安装、覆盖安装保留数据、各机型安装确认与中断行为。

协议和窗口结果只能证明已覆盖的本地行为，不能据此宣称真实 Android 安装或 USB 驱动兼容性已经通过。拿到设备后，应按 docs/product.md 的真机项目验收。

## 发布

发布脚本只复制版本化 EXE，不同步配置、源码、日志或密钥。目标为项目 artifacts 目录和用户指定的 U:\开发工作；复制后检查 SHA-256 一致。构建产物不提交 Git。

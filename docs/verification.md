# QuickADB 0.1.0 验证记录

## 本地协议与状态验证

- 应用安装/队列集成测试：10 项通过。
- SDK 配对测试：12 项通过，包含 SPAKE2 协议向量、错误配对码、配对凭据持久化和重新连接的协议夹具。
- 覆盖官方 ABB 参数分隔、实际 APK 字节传输、确认后进度、取消、设备拒绝、最终结果丢失、拆分包会话及清理、旧设备能力分支。
- 两台夹具设备并行传输，同一设备按提交顺序安装。取消设备选择不改变已提交任务的目标。
- 授权私钥以 DPAPI 保护；重新打开数据目录保留同一身份。损坏的设置文件明确失败，不静默重置。
- 安装测试的 APK 是二进制 Manifest/ZIP 夹具，服务端是本地协议夹具，不是 Android 手机或签名发布包。

## 构建与窗口

- 静态 C 运行库构建、Cargo.lock 锁定依赖。
- 原生应用 Clippy 严格检查通过。
- Release 导入表只包含 Windows 系统 DLL，没有外部 ADB、.NET 或应用 DLL。
- Release 已检查静默托盘启动、托盘展开、关闭后继续常驻、再次展开和退出菜单结束进程。
- 设备列表已使用实际应用连接本地协议夹具，检查多选、连接状态、长备注截断。
- 字号、主题、连接弹窗和拖放区按 docs/ui-layout.md 进行最终窗口验收；截图与测量输出保存在忽略的 logs 目录。
- 实际控件测量：两个 APK 操作按钮均为 178 × 40，按钮组居中偏差 0.5，按钮间距 9，提示文字与按钮间距 16 个逻辑像素。
- 样式绑定到应用选定主题，避免启动后的系统主题输入切换到默认字号。辅助文字为 13，实测提示文字高度为 17 个逻辑像素。
- 浅色与深色连接弹窗在淡入动画结束后检查，标签、输入提示、准备说明和操作按钮无重叠；主文字、辅助文字及选中状态分别使用对应主题颜色。

## 真机验收缺口

用户目前无法提供真机，本机 ADB 设备列表也没有连接的手机。以下内容没有用真机验证：USB 驱动与手机授权、Android 无线配对、签名 APK 实际安装、覆盖安装保留数据、各机型安装确认与中断行为。

协议和窗口结果只能证明已覆盖的本地行为，不能据此宣称真实 Android 安装或 USB 驱动兼容性已经通过。拿到设备后，应按 docs/product.md 的真机项目验收。

## 发布

发布脚本只复制版本化 EXE，不同步配置、源码、日志或密钥。目标为项目 artifacts 目录和用户指定的 U:\开发工作；复制后检查 SHA-256 一致。构建产物不提交 Git。

## 0.1.1 图标与连接界面

- EXE 和窗口保留原黑色圆角应用图标；托盘单独使用新绘制的绿色安装箭头。原始 PNG 分别归属 AppIcon 和 TrayIcon，不互相替换。
- 两套导出均按 alpha 可见边界裁掉多余透明留白，保留圆角透明；检查所有 ICO 条目的尺寸、透明角和可见边界。16 像素条目两者可见图形均为 14 × 14，托盘 32 像素条目为 30 × 29。
- 应用图标提供 16/20/24/32/40/48/64/96/128/256 条目；托盘提供 16/20/24/32 条目。托盘使用 EXE 内独立资源和 LoadIconMetric，不把整个带宽留白的 PNG 缩入托盘。
- 启动验证发现默认系统 Comctl32 没有 LoadIconMetric 导出；已在内嵌清单声明 Windows Common-Controls 6。修正后实际 Release 正常启动，已有窗口和托盘生命周期未被替换。
- 本机实际托盘截图确认绿色箭头；Windows 将此新图标放在隐藏图标区域，展开后验证，没有修改用户的托盘排列设置。实际截图保存为 logs/tray-0.1.1-actual.png。
- 最终发布 EXE 在隔离的数据目录中验证正式托盘菜单打开、关闭后常驻、再次打开和退出，全部通过。当前验证进程 GetCursorPos 返回拒绝访问（错误 5），托盘库因此不派发鼠标点击回放；没有更改或绕开产品点击逻辑，此次鼠标点击验收须在可读取输入桌面的正常 Windows 会话补验。
- 本机 UIAutomation 验证图钉的取消固定/固定抽屉操作及设置持久化；通过实际应用连接本地协议夹具与 mDNS 广播，不使用另写的界面或假状态。
- 本机发现列表显示广播型号 Pixel 8 与传统设备名称；点击配对/无线连接/传统 TCP 服务分别得到 43002/43001/43003，配对与连接端口没有混用。撤销配对广播后仅保留无线连接服务。
- 连接弹窗说明手机先打开配对码弹窗；列表区分配对服务、TLS 连接和传统 TCP。内容超出抽屉高度时滚动，修正滚动区初始高度造成的字段裁切；最终窗口截图保存为 logs/connection-0.1.1-final.png。
- SDK 发现测试 4 项及安装队列/存储测试 2 项通过；原生 Clippy 严格检查与最终 Release 构建通过。安装与配对核心路径未更改，复用上文仍有效的协议验证记录。
- 真机验收缺口保持不变：以上无线发现、端口填入和撤销是本地广播夹具；没有据此声称手机授权、真实 Android 配对或 APK 安装已验证。
- 发布文件 QuickADB-0.1.1-x64.exe 为 15,304,704 字节，导入表仅含 21 个 Windows 系统依赖。项目 artifacts 和 U:\开发工作 副本 SHA-256 均为 E3DE74826ACA0396E9180E2276BCF496873AC60AD8930E129E86D0E70E76ECCC。

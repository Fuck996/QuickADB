# QuickADB 产品与验收约定

## 范围

Windows 便携应用，连接 USB 与同一局域网 Android 设备，以 APK 安装测试为核心。不提供文件浏览、文件传输、投屏、跨互联网远程服务器或源码调试器。

## 抽屉

- 托盘单击展开，点击外部收起，后台任务继续。
- 固定后保持展开，拖动标题区域移动；置顶单独开关。
- 可收成窄栏，再次点击展开。记住固定位置，恢复时限制到有效显示器工作区域。
- 开机启动为用户登录后静默进入托盘，由设置开关控制。
- 关闭窗口收回托盘，退出通过应用菜单；安装进行中退出需要应用内确认。

## 设备与安装

- 简单设备列表直接显示在抽屉，单击选中、再单击取消，无需按 Ctrl。
- 单选和多选使用同一列表；默认不替用户选设备。
- 在线、未授权、离线与断开保持真实区分，设备变化自动更新。
- 没有选中在线设备时，文件不会开始安装；不自动换到其他设备。
- 拖入一个或多个独立 APK 后，为提交时选中的设备创建安装任务，之后的选择变更只影响新任务。
- 同一设备串行安装，不同设备可同时安装。明确显示每项结果。
- 传输按真实字节显示百分比与速度，系统安装使用动态状态，不伪造安装百分比。
- 默认覆盖更新并保留数据；不自动卸载、降级或授予全部运行时权限。
- 失败保留原始错误和中文说明，可单独重试；传输中断或安装结果未知不能表示成功。
- 普通批量 APK 与一个应用的拆分 APK 必须明确区分。

## 无线连接

- Android 11 及以上使用配对码连接，配对端口与连接端口分开输入。
- 旧版 USB 转无线为明确操作，不自动改变手机的调试配置。
- 设备备注、详情、无线断开与连接记录在管理界面提供。
- 不自动重启或终止其他工具使用的 ADB server。

## 视觉与素材

- 主窗口：标题栏、紧凑设备列表、APK 拖放区、任务列表、状态栏。
- 设备管理：连接记录和设备详情；连接表单使用应用内模态。
- 设置：常驻行为、启动、主题与必要安装选项。
- 空态、加载、禁用、传输中、系统安装中、失败与完成状态均需要清楚呈现。
- 参考图仅上方黑色圆角图标作为全局应用图标。下方品牌字样与标语不作为资源。
- 图标已通过内置 imagegen 的背景提取流程生成，保存为 assets/AppIcon.png；不用于任何页面背景。
- 图标提示：只提取参考图上方黑色圆角应用图标，保留绿色 Android、速度线、白色 APK 文件和内部 APK 字母；移除外部白底、下方 QuickADB 与标语；外部透明，不重新设计。

## 交付与证据

- 用户已选择原生单 EXE：不依赖 .NET，不释放应用 EXE/DLL，不依赖外部 adb server。设置、日志与受保护的设备授权数据可以持久保存。
- 验证包括协议集成、设备选择与队列隔离、中文/空格路径、失败与中断、窗口和托盘行为、发布包内容。
- 真机验收包括 USB 授权、无线配对与连接、覆盖安装保留数据、多设备、多 APK、安装失败与连接中断。
- 缺少真机时应保留验收缺口，不能用模拟协议测试宣称真实设备已验证。

# QuickADB 0.9.6

Windows x64 单 EXE APK 安装工具，支持 USB、同一局域网无线、多设备与托盘抽屉。

## 本次改进

- 空闲无线断线只更新为离线，保留设备选择、名称、待安装包与已完成任务；原始原因保留在详情及日志。
- 用户操作提示 8 秒后自动收起，可手动关闭或查看完整详情；重复操作重新计时。传输或安装中断仍在对应任务中显示失败或结果未知。
- 抽屉按安装包准备区的实际高度分配设备列表空间，主安装按钮保持可见，长提示不会裁掉按钮。标准窗口很矮时准备详情滚动，选择和安装操作留在卡片内。

## 使用

1. 开启手机调试，通过 USB 或同一局域网无线连接设备。Android 11+ 无线配对需先在手机打开配对码弹窗，再输入 IP、配对端口和六位配对码；连接端口默认自动发现。
2. 单击设备行选中安装目标，可多选；离线的已保存无线设备会在安装前尝试重连。
3. 拖入或选择 APK，检查准备完成后点击“安装到 N 台设备”。拆分 APK 需一起选择同一应用的基础包与拆分包。

更多功能、窗口操作及构建方法见 [README](https://github.com/Fuck996/QuickADB/blob/main/README.md)。

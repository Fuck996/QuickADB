# QuickADB 0.9.10 macOS 测试版 5

适用于运行 **macOS 27 的 Apple 芯片 Mac**。打开 DMG，将 QuickADB 拖到「应用程序」。已安装带在线更新功能的测试版，可使用「QuickADB → 检查更新…」升级。

- 修复 RP DUO 更换无线调试广播名称和端口后无法重连的问题。QuickADB 会尝试与已保存序列号匹配的广播，连接后读取设备序列号，核对通过后才接受会话。
- 菜单栏图标左键打开安装抽屉，右键可打开主窗口、进入设置、检查更新或退出。可在「设置 → 常驻」隐藏 Dock 图标。
- 设置中的「版本与更新」显示完整测试版编号，可直接检查更新。

本机已用原配对记录和新端口恢复 RP DUO 的连接。协议夹具覆盖旧端口失效、同一设备换广播名称、拒绝序列号不符的连接，以及自动、手动和安装前重连。新版自动重连仍待 RP DUO 真机断线复验。

安装包使用临时签名。首次打开或升级后，macOS 可能要求确认打开或重新授权访问钥匙串。 [Apple 的应用安全说明](https://support.apple.com/zh-cn/102445)

发布附件包含安装镜像、SHA-256 校验文件、完整对应源码和法律声明。

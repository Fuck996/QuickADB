# QuickADB 0.9.10 macOS 测试版 3

适用于运行 **macOS 27 的 Apple 芯片 Mac**。打开 DMG，将 QuickADB 拖到「应用程序」。

- 菜单栏采用从 App 图标提炼的单色图标，保留 Android 头像、APK 折角文件和速度线，随系统外观自动着色。
- 启动时只读取一次已有的 ADB 钥匙串条目，后续连接与配对复用同一把私钥。原配对记录继续有效。
- 支持通过「QuickADB → 检查更新…」获取 GitHub 上的新版 Mac 测试版。确认后校验安装镜像并等待当前任务结束，再替换原位置的应用并重新打开。

若使用 GitHub 上的 Beta 1，请先用此 DMG 升级一次。已安装带在线更新功能的本地 Beta 2，可在应用内检查并升级到 Beta 3。

安装包使用临时签名，尚未经过 Developer ID 签名和 Apple 公证。首次打开或升级后，macOS 可能要求确认打开或重新授权访问钥匙串。 [Apple 的应用安全说明](https://support.apple.com/zh-cn/102445)

发布附件包含安装镜像、校验文件、完整对应源码与法律声明。在隔离副本中验证了 GitHub 下载、签名、替换和回滚。真实 Android 设备的 USB 授权和首次无线配对仍待验收。

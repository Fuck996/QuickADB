# QuickADB 0.9.9 macOS 测试版 1

适用于运行 **macOS 27 的 Apple 芯片 Mac**。打开 `QuickADB-0.9.9-mac-beta.1-arm64.dmg`，把 QuickADB 拖到「应用程序」。

- 新增原生工具栏、设备侧栏和菜单栏安装抽屉。使用图钉可固定抽屉。
- USB、无线连接、APK 文件准备和安装使用共用的 Rust 后端。
- 配对与 USB 授权使用 macOS 钥匙串保存的独立 ADB 密钥。首次使用请在 Android 上对 Mac 重新授权或配对。

此预发行安装包为本地测试签名，尚未经过 Developer ID 签名和 Apple 公证。下载后，macOS 可能提示开发者无法验证。 [Apple 的应用安全说明](https://support.apple.com/102445)

完整对应源码、许可和 SHA-256 校验随附在 GitHub 预发行页面。真实 Android 设备的 USB 授权、无线首次配对、覆盖安装及 Finder 界面体验仍待验收。 [构建与验收](../macos.md)

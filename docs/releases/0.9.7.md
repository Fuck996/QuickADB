# QuickADB 0.9.7

修复标准窗口侧栏的设备详情入口，补齐连接配置编辑和已配对设备删除。

## 本次改进

- 设备卡片使用 egui 官方的父级点击感知方式，详情按钮优先接收点击；打开详情不会同时选中或取消设备。
- 在详情或设备管理中编辑连接地址，保存后重新连接。连接失败、尚未成功保存的设备也能修改，备注和已知设备身份随记录保留；已配对设备可以恢复自动发现。
- 删除无线设备前明确确认；删除会断开连接、清理本机配对和连接、名称记录，并同步主列表。重启后不会恢复，也不会因附近的无线广播自动重连。其他设备授权与已完成任务保留。
- 正在建立的旧连接可取消；编辑或删除不会被旧请求覆盖。设备有安装任务时需先完成或取消任务，安装不会被转移到其他地址。
- 发布流程同时生成完整对应源码与法律声明，完成后清理本次源码暂存目录。

删除本机配对记录不会撤销手机端的电脑授权。如需撤销，请在手机无线调试的已配对设备中选择“忘记”。

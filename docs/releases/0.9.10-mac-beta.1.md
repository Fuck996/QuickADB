# QuickADB 0.9.10 macOS 测试版 1

适用于运行 **macOS 27 的 Apple 芯片 Mac**。打开 DMG，将 QuickADB 拖到「应用程序」。

- 无线配对自动获取手机地址和配对端口。发现一台时直接输入六位配对码，发现多台时先选手机。保留手动输入入口。
- 菜单栏采用更大的系统安装箭头，随菜单栏外观自动着色。

安装包使用本地测试签名，尚未经过 Developer ID 签名和 Apple 公证。首次打开时 macOS 可能提示无法验证应用。 [Apple 的应用安全说明](https://support.apple.com/zh-cn/102445)

发布附件包含 DMG、校验文件、完整对应源码与法律声明。真实 Android 设备的 USB 授权、首次无线配对和 APK 覆盖安装仍待验收。

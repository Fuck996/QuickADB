# QuickADB 0.9.10 for Windows

适用于 Windows x64，下载 EXE 后可直接运行。

- 无线配对通过局域网自动获取地址和端口。发现一台时只需输入六位配对码，发现多台时先选手机。保留手动输入地址和端口的入口。
- 启动和常驻期间自动检查 GitHub Releases 正式版，可在托盘和设置手动检查。确认更新后校验下载大小和 SHA-256，等待安装任务结束，再替换 EXE 并重新打开。
- EXE 的更新目录需要可写，设置、日志和设备授权继续保存在原数据目录。

EXE 未进行 Authenticode 签名。真实 Android 设备的首次无线配对与实际跨版本自更新仍待验收。

发布附件包含 EXE、完整对应源码与法律声明。

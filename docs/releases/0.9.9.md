# QuickADB 0.9.9

修正 Windows 刷新时的图形上下文生命周期，用户报告的整窗闪黑仍待现场复验。

## 本次变更

- 回移 eframe 官方 [PR #8461](https://github.com/emilk/egui/pull/8461) 最终合并补丁。原路径每帧在清屏前和内容绘制前都解绑、重新绑定同一个 GL 上下文；现在记录当前绑定的窗口，仅在实际需要时切换。
- 同时处理窗口重建、销毁、挂起和多窗口的绑定状态，避免把其他窗口的图形表面当作当前目标。使用原来的 Glow 硬件渲染、动画和实时安装进度。
- 增加可重复运行的 Windows 原生绘制回归：通过原 Drawer、Backend 和本机协议设备安装，检查绘制后的 GPU 缓冲与 GL 错误，覆盖窗口大小、抽屉模式、隐藏恢复、子窗口关闭和主题切换。

## 验证边界

后台状态快照没有先清空再填充设备或任务。本次修正了源码与上游记录共同确认的重复上下文切换问题；上游记录证明的是生命周期与性能问题，尚不能证明它就是用户长时间运行实例发生黑闪的唯一原因。隔离窗口通过不等于真实故障已经消失。

详细结果见 [验证记录](https://github.com/Fuck996/QuickADB/blob/main/docs/verification.md)。此次未重新安装真实手机应用，也未关闭用户正在运行的旧版。

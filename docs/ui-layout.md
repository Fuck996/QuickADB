# 抽屉界面布局约定

采用 ui-ux-pro-max 的简约工具界面、网格对齐、统一间距与文字对比度原则。保持原生单 EXE 架构和用户指定的应用图标，不套用网页落地页或移动端导航。

## 主窗口

- 窗口为 440 × 660 个逻辑像素，遵循 Windows 显示缩放。
- 信息顺序固定：标题与常驻操作、安装设备、APK 拖放区、安装任务、底部设备管理与设置。
- 固定抽屉使用图钉图标按钮，保留悬停提示、选中状态与辅助功能名称。
- 正文和普通按钮 15，辅助文字 13，标题 19；应用名称 20，设备名称和任务名称 14。
- 主内容左右各 16，控件间距以 4/8 为基本单位。区域内按钮通过布局系统分列，不使用空白字符或固定偏移定位。
- 设备名称和连接状态独立两行；长备注只截断名称，详情操作保持可见。选中状态同时用标记和边框表达。
- 空拖放区的图标、标题、说明共用中心线。“选择 APK / 选择拆分 APK”是两列等宽等高的次级操作，下面独立提供整行主安装按钮。
- 准备后在原区域显示文件列表、检查状态与总大小，支持清空、逐项移除与更换；长文件名截断并可悬停查看完整路径。列表有高度上限，检查失败显示真实错误，主安装按钮与任务区始终保留。
- 没有待安装内容、正在检查、检查失败或没有选中在线设备时禁用安装；按钮标明目标设备数量。多个 APK 可显式切换为拆分安装，重新检查同一组文件。
- 安装任务保留独立滚动区，底部管理入口不被任务覆盖。

## 连接弹窗

- 居中的应用内模态，标题、用途说明、连接方式、手机准备提示、字段、主操作依次排列。
- 无线配对、已配对设备和 TCP 连接各有对应说明。
- 无线配对默认显示 IP 地址、配对端口和六位配对码；后两项占两列。连接端口不作为配对的必填条件。
- 已配对设备先选择配对记录，默认自动获取当前地址与连接端口；记录显示已知型号、备注或真实服务名。
- “手动填写连接端口（可选）”默认收起，发现不可用时可展开填写无线调试主页的地址与端口；非空无效端口在主操作前显示错误。传统 TCP 仍显示必填 IP 和连接端口。
- 主操作占整行，提交条件不足时禁用；配对中显示真实等待状态。
- 发现列表显示型号或真实服务名称、服务类型和地址。配对页只列配对服务；已配对页只列 GUID 与授权记录匹配的连接服务，选择后自动获取端口；传统 TCP 页只列传统服务。设备撤销广播后从列表移除。
- 内容超过窗口高度时在弹窗内滚动，保证不裁切表单与操作。
- 浅色与深色分别检查文字、边框、选中标签和禁用按钮。

## 素材归属与验收

- AppIcon.png：原黑色圆角应用图标，用于 EXE、窗口和标题。导出时去除多余透明留白；AppIcon.ico 提供 Windows 多尺寸资源，AppIconDisplay.png 用于窗口和标题。
- TrayIcon.png：绿色圆角方形安装箭头，仅用于托盘。单独导出 16/20/24/32 像素的 TrayIcon.ico，按系统尺寸从 EXE 资源加载。两套素材均保留透明圆角，不共享用途。
- APK 线框符号：拖放区域的提示图形，由原生绘制生成。
- 背景、卡片、按钮、输入框：共享界面样式，不使用临时图片作背景。
- Windows 系统微软雅黑：中文界面字体。

用户反馈图中框出的对象对应拖放区“选择 APK / 安装拆分 APK”按钮行。验收须使用实际窗口与控件边界，检查按钮组中心线、等宽等高、按钮间距、提示文字间距；同时检查两台已选设备和长备注场景。主题和字号配置必须在启动后的系统主题输入到达后仍然生效。

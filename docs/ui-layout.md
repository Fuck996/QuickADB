# 抽屉界面布局约定

采用 ui-ux-pro-max 的简约工具界面、网格对齐、统一间距与文字对比度原则。保持原生单 EXE 架构和用户指定的应用图标，不套用网页落地页或移动端导航。

## 主窗口

- 抽屉为 440 × 780 个逻辑像素，遵循 Windows 显示缩放；恢复和展开时限制大小与位置到实际显示器工作区域。
- 标准窗口默认内容区 1080 × 800，最小内容区 440 × 480；使用 Windows 原生标题栏和窗口边框，支持调整大小、最大化与系统贴靠，任务栏使用原应用图标。标题区的窗口图标及设置页共用模式切换，切换复用当前设备、待安装文件与任务。
- 信息顺序固定：标题与常驻操作、安装设备、APK 拖放区、安装任务、底部设备管理与设置。
- 底部提示限制在单行可用宽度内，关闭按钮独立预留；点击提示打开完整文本和复制操作。无论提示长度与换行多少，底部操作不越出窗口，提示不能撑宽设备与任务区域。
- 固定抽屉使用图钉图标按钮，保留悬停提示、选中状态与辅助功能名称。
- 图钉固定同时设置真实系统置顶并禁止失焦自动收起；启动、托盘重新展开、图钉和设置页使用同一窗口层级规则。固定时设置中的置顶项显示为已启用且不可取消；取消固定后恢复独立置顶设置。
- 正文和普通按钮 15，辅助文字 13，标题 19；应用名称 20，设备名称和任务名称 14。
- 主内容左右各 16，控件间距以 4/8 为基本单位。区域内按钮通过布局系统分列，不使用空白字符或固定偏移定位。
- 设备名称和连接状态独立两行；长备注只截断名称，详情操作保持可见。选中状态同时用标记和边框表达。
- 空拖放区的图标、标题、说明共用中心线。“选择 APK / 选择拆分 APK”是两列等宽等高的次级操作；准备文件后，下面独立提供整行主安装按钮。
- 准备后在原区域显示文件列表、检查状态与总大小，支持清空、逐项移除与更换；长文件名截断并可悬停查看完整路径。列表有高度上限，检查失败显示真实错误，主安装按钮与任务区始终保留。
- 正在检查、检查失败或没有选中可安装设备时禁用安装；已保存的离线无线设备可选，安装前尝试重连。按钮标明目标设备数量。多个 APK 可显式切换为拆分安装，重新检查同一组文件。
- 设备与准备区域超出可用空间时局部滚动，为安装任务保留独立滚动区；底部提示按实际高度布局，管理入口不被任务覆盖。

## 连接弹窗

- 居中的应用内模态，标题、用途说明、连接方式、手机准备提示、字段、主操作依次排列。
- 无线配对、已配对设备和 TCP 连接各有对应说明。
- 无线配对默认显示 IP 地址、配对端口和六位配对码；后两项占两列。连接端口不作为配对的必填条件。
- 已配对设备先选择配对记录，默认自动获取当前地址与连接端口；记录显示已知型号、备注或真实服务名。
- “手动填写连接端口（可选）”默认收起，发现不可用时可展开填写无线调试主页的地址与端口；非空无效端口在主操作前显示错误。传统 TCP 仍显示必填 IP 和连接端口。
- 主操作占整行，提交条件不足时禁用；配对中显示真实等待状态。
- 发现列表置于连接说明之后、手动输入之前，始终显示全部广播服务的型号或真实服务名称、服务类型和地址，不按当前标签或授权记录隐藏新设备。列表自动更新，没有广播时保留明确空态；同一手机可能有配对和连接两个服务，不按 IP 合并身份。
- 点击配对服务填入配对端口；点击有本机配对记录的连接服务切换到已配对页并自动获取端口；点击无本机配对记录的连接服务切换到配对页，仅填入 IP，提示在手机打开配对码弹窗；点击传统服务切换到 TCP 页并填入连接端口。切换服务时清除旧配对码和端口，设备撤销广播后从列表移除。
- 抽屉增高后，弹窗可用内容高度增加为窗口高度减 48；标准窗口中的弹窗宽度可达 520。内容超过窗口高度时在弹窗内滚动，保证不裁切表单与操作。
- 浅色与深色分别检查文字、边框、选中标签和禁用按钮。

## 标准窗口工作台

用户反馈图 `codex-clipboard-64bfff0a-345d-401a-a2db-7a64c639d392.png` 对应旧窗口模式：`header` 占据整行，`preparation_ui` 与 `installation_tasks` 两等宽列并排。该版本没有独立设备栏，安装包与设备挤在一列，任务区留白大；此结构不作为标准窗口的最终设计。

- 顶部：原生系统标题栏之下使用紧凑命令栏，显示应用图标、安装工作台标题、设置、图钉与模式切换。没有抽屉宣传副标题和重复的最小化/关闭按钮。
- 左侧：宽度达到 760 时显示独立设备栏，默认宽度 272，可拖动分隔线调整到 228～360。设备栏占满主体高度，顶部设备数量、选择操作及连接入口，中部滚动设备卡片，底部说明和设备管理。名称允许换行，详情在卡片内；USB 未授权设备仍可查看详情。
- 右上：安装包工作区，标题显示目标数量，文件准备区使用横向图标和说明、文件列表、选择/更换/拆分操作及开始安装按钮。无文件时开始安装可见但禁用；有文件时仍须检查通过、用户点击后才提交到既有队列。
- 右下：安装任务占据剩余高度，标题与清理操作固定，宽度充足时使用安装包、目标设备、状态、操作四列。传输字节进度及原始结果沿用同一任务记录。空态说明下一步操作，不填充假任务或演示统计。
- 窄窗口：设备栏收成可展开的设备选择区，安装包和任务仍上下排列；任务宽度不足时回到卡片显示。全局操作保持可访问，不出现横向滚动。
- 底部：单行状态栏显示在线数量、选择数量和受限宽度的提示；完整提示通过同一详情弹窗查看。标准窗口不因失焦收起，关闭仍回托盘，并独立保存大小和位置。
- 素材：应用图标、APK 符号和图钉/窗口图标属于共享设计资产；设备、准备文件与任务来自既有后台快照。此布局不增加图片背景、临时模拟数据或另一套安装流程。

验收分别检查宽窗口、窄窗口、最大化、浅色/深色、无文件、文件准备完成、任务完成及错误详情。原生 EXE 的窗口验收与直接复用生产 UI 的协议夹具验收须分别记录。

## 素材归属与验收

- AppIcon.png：原黑色圆角应用图标，用于 EXE、窗口和标题。导出时去除多余透明留白；AppIcon.ico 提供 Windows 多尺寸资源，AppIconDisplay.png 用于窗口和标题。
- TrayIcon.png：绿色圆角方形安装箭头，仅用于托盘。单独导出 16/20/24/32 像素的 TrayIcon.ico，按系统尺寸从 EXE 资源加载。两套素材均保留透明圆角，不共享用途。
- APK 线框符号：拖放区域的提示图形，由原生绘制生成。
- 背景、卡片、按钮、输入框：共享界面样式，不使用临时图片作背景。
- Windows 系统微软雅黑：中文界面字体。

用户反馈图中框出的对象对应拖放区的 APK 选择按钮行。验收须使用实际窗口与控件边界，检查按钮组中心线、等宽等高、按钮间距、提示文字间距；同时检查两台已选设备和长备注、待安装列表、失败提示及独立安装按钮。主题和字号配置必须在启动后的系统主题输入到达后仍然生效。

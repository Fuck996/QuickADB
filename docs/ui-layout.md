# 抽屉界面布局约定

采用 ui-ux-pro-max 的简约工具界面、网格对齐、统一间距与文字对比度原则。保持原生单 EXE 架构和用户指定的应用图标，不套用网页落地页或移动端导航。

## 主窗口

- 窗口为 440 × 660 个逻辑像素，遵循 Windows 显示缩放。
- 信息顺序固定：标题与常驻操作、安装设备、APK 拖放区、安装任务、底部设备管理与设置。
- 正文和普通按钮 15，辅助文字 13，标题 19；应用名称 20，设备名称和任务名称 14。
- 主内容左右各 16，控件间距以 4/8 为基本单位。区域内按钮通过布局系统分列，不使用空白字符或固定偏移定位。
- 设备名称和连接状态独立两行；长备注只截断名称，详情操作保持可见。选中状态同时用标记和边框表达。
- 拖放区的图标、标题、说明共用中心线。操作区为两列等宽、等高的按钮，整体居中；说明与按钮不重叠。
- 安装任务保留独立滚动区，底部管理入口不被任务覆盖。

## 连接弹窗

- 居中的应用内模态，标题、用途说明、连接方式、手机准备提示、字段、主操作依次排列。
- 无线配对、已配对设备和 TCP 连接各有对应说明。
- IP 地址与连接端口占整行，配对端口和六位配对码占两列；标签持久可见，输入示例只作辅助。
- 配对端口取自手机配对弹窗，连接端口取自无线调试主页，两者明确区分。
- 主操作占整行，提交条件不足时禁用；配对中显示真实等待状态。
- 浅色与深色分别检查文字、边框、选中标签和禁用按钮。

## 素材归属与验收

- AppIcon.png：全局应用图标，用于标题与托盘，保留指定的黑色圆角图标。
- APK 线框符号：拖放区域的提示图形，由原生绘制生成。
- 背景、卡片、按钮、输入框：共享界面样式，不使用临时图片作背景。
- Windows 系统微软雅黑：中文界面字体。

用户反馈图中框出的对象对应拖放区“选择 APK / 安装拆分 APK”按钮行。验收须使用实际窗口与控件边界，检查按钮组中心线、等宽等高、按钮间距、提示文字间距；同时检查两台已选设备和长备注场景。主题和字号配置必须在启动后的系统主题输入到达后仍然生效。
